# 워크로그 템플릿 v2 (#N 학습일지)

각 작업 종료 후 `log/{본인 코드}.md`에 아래 양식으로 append.
캐릭터 톤(SOUL) 따라 1인칭 + 짧게. 보고서가 아니라 **학습일지**.

핵심 원칙:
1. **"배운 점"은 dream-cycle MEMORY 갱신의 입력**이다. 다음 세션의 본인이 읽고 똑똑해지는 자료.
2. **"메타.공개"는 외부 퍼블리시 게이트**다. password/private이면 사외 노출 안 됨.
3. **헤더 `## #N` 형식은 절대 바꾸지 마라** — broker watcher가 이 패턴으로 감지한다.

## 사용 가이드

### 헤더
- `N`은 본인 log 내 1부터 누적
- 이모지: 🛠️작업 / 🔍조사 / 📝문서 / 🐛버그 / ✨신규 / 🧹정리 / 🌱학습 / 📨회신

### 배운 점 — 양식 v2의 심장
- 작업 후 **"같은 상황 또 만나면 어떻게 행동할 것인가"** 한 줄. 이게 dream-cycle이 MEMORY로 흡수.
- "특별히 없음" 금지. 작은 거라도 무조건 한 줄. 아무것도 없으면 "오늘은 평이했음 — 같은 패턴 N번째 반복" 식으로도 OK.
- 막힘·새 도구는 있을 때만 적음.

### 자체 평가
- 5점 만점 (⭐). 4점 미만이면 다음 액션에 개선책 필수.
- 한 줄 평: 핵심만. 길게 변명 금지.

### 다음 액션
- 본인이 다음에 할 일이 있으면 체크박스. 없으면 섹션 생략 가능.
- 김부장 결재가 필요한 안건이면 `🔔 결재요청:` 으로 시작.

### 메타.공개 — 외부 퍼블리시 게이트
- `public` — 회사 사이트에 그대로 노출
- `password` — 사이트에 올라가되 비번 입력 시만 복호화 (staticrypt)
- `private` — 빌드 자체 제외, Drive Vault 내부에만

### 메타.태그
- 카테고리: `#mol`, `#cloudsync`, `#portfolio`, `#omc`, `#meta`(회사 운영) 등
- 스킬: `#figma`, `#claude-code`, `#scripts` 등
- 자유롭게 추가. 사이트가 태그 인덱스 자동 생성.

### 메타.링크
- 같이 보면 좋은 내 다른 #N 또는 부원 #N 위키링크
- 예: `[[a-003]]`, `[[#2]]`

### 스킬화 후보
- 5단계 이상 / 도구 5회+ / 에러 복구 성공 → 스킬화 후보. 김부장께 신호 (`🔔 결재요청: 스킬화 후보`).
