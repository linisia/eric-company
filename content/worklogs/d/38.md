- **패턴/원칙:** Notion이 markdown link 결을 시간 지나면 또는 UI 결로 `<unknown alt="external_object_instance"/>` 결로 자동 변환한다 — 본인 결로 직접 박지 못해도 결재선 결로 5분 기다리면 결이 갈리는 결이 있다. 같은 결의 task 또 만나면 첫 시도는 bare URL markdown link 결, 둘째 결단은 결 한 호흡 기다린 뒤 fetch로 갈림 확인. 본인이 박을 결 없으면 결재선 결로 결단.
