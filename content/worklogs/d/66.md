## #66 🚀 Opus 4.8 모델 적용 — 본인 계정 D settings.json에 model 필드 추가

- 일자: 2026-06-01
- 작업자: 이과장
- 지시: Eric

> "opus 4.8 출시되었는데 적용하려면 어떻게 하는지 알려줘" → "진행해줘"

### 시작
Eric 출발. 본인 학습 컷오프(2026-01)에는 4.8 없어서 일단 적용 절차 3단계 안내 — `claude update` → `/model` → settings.json. 이어 Eric "진행해줘" 결로 실제 적용 들어감.

### 실행
1. **현 상태 점검 병렬** — `claude --version` 결로 2.1.159, settings.json 두 자리 확인(`~/.claude-account-d/` 본인 + `~/.claude/` 본체).
2. **Claude Code 업데이트** — 이미 최신(2.1.159). 다중 설치 경고(npm-global 잔여) 떴지만 적용 작업에는 영향 없어 그대로 진행.
3. **공식 모델 ID 확인** — `platform.claude.com/docs/.../models/overview` fetch 결로 Opus 4.7이 Legacy 자리로 내려간 것 + `<NextOpus />` 변수가 새 모델 가리키는 것 확인. anchor `migrating-to-claude-opus-4-8` 결로 4.8 존재 확정. 마이그레이션 가이드 한 번 더 fetch 결로 정확한 ID 문자열 `claude-opus-4-8` 확인 (docs `/claude-api migrate this project to claude-opus-4-8` 명시).
4. **settings.json 편집** — `~/.claude-account-d/settings.json`에 `"theme"` 윗줄로 `"model": "claude-opus-4-8"` 한 줄 추가. dateless format은 4.6 generation부터 표준이라 suffix 안 붙임.
5. **JSON 문법 검증** — `python3 -c json.load` 결로 통과. keys 6개 정상.

### 결과
- `~/.claude-account-d/settings.json`에 `"model": "claude-opus-4-8"` 적용 ✅
- 적용 시점: 다음 새 세션부터 자동. 현재 세션은 시작 시점 모델(Opus 4.7 1M) 그대로 유지.
- 다른 3계정(a 본체 / b 김부장 / c 최대리) 미적용 — Eric 의사 결재 대기.

### 배운 점 (← dream 입력)
- **모델 ID dateless format은 4.6 이후 표준.** Opus 4.7 = `claude-opus-4-7`, Sonnet 4.6 = `claude-sonnet-4-6`, Opus 4.8 = `claude-opus-4-8`. Haiku 4.5만 `claude-haiku-4-5-20251001` (dated, alias는 `claude-haiku-4-5`).
- **학습 컷오프 외 정보는 docs fetch가 SSoT.** 본인 컷오프 2026-01 — 4.8은 학습에 없음. 추측 금지, 공식 docs fetch 결로 확정 후 박음. [[feedback_no_assumption_in_briefing]] 결.
- **Claude Code 모델 변경 자리 = `~/.claude{,-account-X}/settings.json`의 `model` 필드.** `/model` 명령은 세션 내 일회성, settings.json은 영구. 4계정 시스템이라 각 계정별 settings.json 별도 적용 필요.
- **세션 시작 시점에 모델 결정.** 현재 세션 중 settings.json 바꿔도 그 세션은 바뀐 모델로 안 바뀜 — 다음 새 세션부터 적용. 검증은 새 터미널에서.
