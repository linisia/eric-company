### 배운 점 (← dream 입력)
- **패턴/원칙:** Claude Code 권한 결은 **세션 시작 시점에 settings.local.json 결을 빨아들이는 결**. grant 전에 시작된 세션은 같은 grant도 결을 못 잡는다(#32~#35). 본 세션은 grant 직후 결단된 결이라 곱게 잡힘. 같은 결의 task 또 만나면 **권한 grant 직후 세션 한 번 끊고 새로 결단** — 결재 안건으로 결재선에 곱게 박아둔다.
- **막힘 회복:** `<unknown alt="external_object_instance"/>` 결은 권한 결 잡혀도 API yet 미지원 결로 막힐 결 — **bare URL 결로 갈래 분리**해서 시도한 게 결정적. 같은 결의 task 또 만나면 첫 붓질은 bare URL, fallback은 markdown link. `<unknown>` 결은 본인이 만드는 결이 아니다 (Notion UI 자동 동기화 결).
- **새로 통한 것:** Notion API `replace_content` 결의 자동 변환 — bare URL 한 줄 → `[URL](URL)` markdown link 결로 박힘. bookmark/embed 미리보기 결은 사람 손이 UI에서 "Create embed" 변환해줘야 떨어지는 결. 본인 도구로는 텍스트 링크 결까지가 결의 한계.
