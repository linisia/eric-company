## #37 🖥️ #T-C-122 대시보드 v1 — 반응형 + 작업 리스트 + dismiss

- 일자: 2026-05-18
- 작업자: 최대리
- 지시: Eric

> "카드 4장 가로 고정이라 절반 분할/노트북에서 잘림. 카드 아래 작업 리스트 + dismiss 박아."

### 시작
14:00. v0 띄워본 결과 두 결 보강: (1) 반응형 (2) 작업 리스트 + dismiss. queue.md 파싱이 결 가장 까다롭다는 결재 — 4 부원 헤더 패턴 먼저 훑고 진입.

### 실행
1. **헤더 패턴 회귀** — 4명 큐 헤더 결 한 번씩 grep. `### (✅|❌|⏸️)? #T-X-NNN  제목...` 결로 통일됨. step 헤더(`#T-C-101-step1`)도 `[\w-]+`로 받힘. b 김부장은 큐 자체가 비어 있음(직지시 룰). 정규식 한 방: `^###\s*(✅|❌|⏸️)?\s*#T-([A-Da-d])-([\w-]+)\s*(.*?)\s*$` + `re.MULTILINE`.
2. **server.py — `/api/tasks` 신규**. `_parse_queue(agent)` mtime 기반 lazy cache (`_QUEUE_CACHE[agent] = (mtime, tasks)`). `_extract_task_id(text)`로 부원 status `current_task` 필드에서 task ID 뽑아 자기 큐의 wait 항목과 매칭 → `active`로 승격. 같은 ID 중복(추가 항목 헤더 재사용) 첫 번째만.
3. **반응형 그리드** — 미디어 쿼리 3단(1100·640) 제거하고 `grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))` 한 줄로 통일. 카드 폭이 280 밑이면 자동으로 줄어들어 노트북 1080p 절반 분할에서도 잘림 X. `.title`·`.task-title`은 `min-width:0` + ellipsis로 카드 폭 따라 자연스럽게 줄어듦.
4. **카드 보강** — `.log-hdr` 한 줄 ellipsis → 2줄 line-clamp + 전체는 `title` 속성으로 hover tooltip. `.gauge`에 `cursor: help` + `title="5h 0% (warn 65% / stop 72%, 갱신 5분 전)"` 결로 0% 빈약함 해소.
5. **작업 리스트 섹션** — 그리드 아래 `<section class="tasks">`. 상태 뱃지(active 펄스 / wait 회색 / hold 주황 / done 흐림 / dropped 빨강). 정렬: active < wait < hold < done < dropped. 기본은 미완료만, "전체 보기" 토글. 모바일 ≤720px에서 한 줄 → 2줄 결.
6. **dismiss localStorage** — key `dashboard.dismissed.taskIds`, JSON array. 행 hover 시 ×버튼 노출. "완료 일괄 dismiss"(done+dropped 한꺼번에) + "dismiss 복원"(localStorage clear). **서버는 queue.md 절대 수정 X — 절대원칙 유지.**
7. **검증** — 8765 이미 v0 점유 중이라 임시 8766으로 별도 서버 띄움. `importlib.util.spec_from_file_location` + 직접 `ThreadingHTTPServer` 박는 결로 module 그대로 import + main() 우회. `/api/tasks` 결 60건, owners {a,c,d}, status mix {done:57, wait:2, dropped:1}, c #T-C-122 + d #T-D-121 정확. `/api/state` 4명 직렬화 정상. 검증 후 8766 shutdown, 8765 v0는 안 건드림.

### 배운 점 (← dream 입력)
- **패턴/원칙:** **상태 변환은 백엔드, 사용자 결정은 클라이언트.** queue.md 상태(✅/❌/⏸️) 파싱·active 승격은 서버에서, dismiss 같은 "이 사람만의 임시 결정"은 localStorage. 서버가 절대 queue.md 안 건드린다는 룰이 깔끔하게 산다. 같은 결 또 만나면 *원본 SoT는 read-only, "표시 합성"은 서버, "내 결정"은 브라우저*로 3계층 분리한다.
- **새로 통한 것:** `repeat(auto-fit, minmax(280px, 1fr))` 한 줄이 미디어 쿼리 3단을 완전히 대체. 카드 디자인이 "최소 폭만 보장되면 알아서 줄 잡힘". 미디어 쿼리 결정 트리는 *실제로 다른 디자인이 필요할 때만* 박는다 — 동일 카드의 단순 정렬이면 auto-fit이 정답.
- **막힘 회복:** 임시 포트로 서버 띄울 때 `m.PORT = 8766` + `spec.loader.exec_module(m)` 결로 1차 시도 → `if __name__ == "__main__"`이 평가되면서 main()이 8765로 들어가 충돌. 우회: `exec_module` 후 별도 `ThreadingHTTPServer(("127.0.0.1", 8766), m.Handler)` 직접 박음. 같은 결: *모듈을 결로만 빌리고 싶을 땐 main()을 우회해서 핸들러만 가져오는 게 깔끔하다*.
- **결 디자인:** active 뱃지에 `::before` 펄스(5px dot)를 박아 텍스트 결을 안 흔들면서 시그널만 살림. dismiss 버튼은 row hover 시 opacity 0→1, 클릭 면적은 22×22 유지. localStorage 결 디자인은 *기본 동작이 곱고, 복원 결도 한 클릭에 있어야 함* — 둘 다 충족.
