### 시작
#68 후속. apidog 블로그가 "Fable 5 = 2.1.170+ 필요, 구독 불가·API 과금 필수"라 주장 → 내 #68 실측(2.1.159서 풀ID 작동)과 충돌. 돈 걸린 문제라 추측 금지·실측 우선.

### 실행
1. **자료 교차검증**: 공식 overview/introducing + apidog. 공식엔 Fable 5 구독 가용성 언급 0, API 단가($10/$50)만. apidog는 구독 불가·API 과금·2.1.170+ 주장(단 "or qualifying plan" 단서 있음).
2. **billing 경로 실측**: b/c/d 전수 — `.claude.json`·`settings.json`·env에 API 키 0개 = 순수 구독 OAuth(`stripe_subscription`). "추가요금" 갈림길은 API 키 유무인데 셋 다 없음.
3. **계정별 접근 probe** (`CLAUDE_CONFIG_DIR=경로 claude -p --model claude-fable-5 --output-format json`): b·c·d 전부 `is_error:false`, `modelUsage:{claude-fable-5}` 명시(폴백 아님). 가짜 ID(`claude-fable-99`) 대조군은 에러·$0 → 접근통제 살아있고 Fable 5만 통과. **3계정 모두 구독으로 사용 가능 확정.**
4. **버전**: npm 최신=2.1.170(apidog 일치), 우리 2.1.159. `claude update` → **2.1.170 성공**(native 공유 바이너리=4계정 공통). 알리아스 `fable`도 2.1.170부터 작동(2.1.159선 실패했던 것).
5. **정책 결정**: AskUserQuestion 3안(온디맨드/전계정기본/c만기본) → Eric "온디맨드" 선택 → 기본 모델 미변경(Opus 4.8 유지), 무거운 작업만 `/model fable`. settings.json 손 안 댐.

### 결과
✅ **추가 청구 없음** — Max 구독으로 b/c/d 모두 Fable 5 사용 가능. 단 환산단가 Opus 2배 = Max 5h·주간 한도 약 2배 속도 소진(trivial 호출 환산 $0.10~0.16, `total_cost_usd`는 청구 아닌 쿼터 환산). ✅ **2.1.170 업그레이드 완료.** ✅ 온디맨드 셋업(파일 변경 0). ⚠️ npm-global에 2.1.159 leftover — PATH상 native 우선이라 무해, 정리 권고만.

### 배운 점 (← dream 입력)
- **패턴/원칙:** "구독 추가요금 여부"는 **API 키 존재 여부 + 계정별 OAuth probe**로 실측. 2차 블로그 주장과 충돌 시 공식문서+실측 2소스로 깬다. `--output-format json`의 `modelUsage`(폴백 판별) + 가짜ID 대조군이 표준 검증쌍.
- **막힘 회복:** 다계정 권한 검증은 `CLAUDE_CONFIG_DIR=경로 claude -p`로 한 세션에서 타 계정 자격 실행 — 이번에 처음 활용한 핵심 기법. foreground `sleep`은 하네스 차단 → run_in_background+알림.
- **새로 통한 것:** `total_cost_usd`는 구독 환경선 "환산 쿼터 차감"이지 카드 청구 아님 — 이 구분이 추가요금 질문의 정답 축. `claude update`가 중복설치 경고+config method 자동교정까지.
