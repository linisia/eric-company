### 실행
1. **진단** — `quartz/components/Date.tsx`의 `formatDate`가 `toLocaleDateString({month:"short"})` 호출 → `May 15, 2026`. 폴더 카운트는 `quartz/components/pages/FolderContent.tsx`의 `showFolderCount` 옵션(default `true`)이 `i18n(...).pages.folderContent.itemsUnderFolder({count})`를 출력. `folderPage.tsx` emitter는 `FolderContent({ sort: userOpts?.sort })`만 forward 중 → 옵션 길 막혀 있음. 풀려면 emitter에서 `showFolderCount: false` 직접 박아야 함.
2. **픽스 — 날짜:** `formatDate` 내부를 `toLocaleDateString` 대신 `getFullYear/getMonth/getDate` padStart로 `${y}.${m}.${d}` 수동 포맷. locale 인자는 시그니처만 유지 (호출부 안 깸).
3. **픽스 — 폴더 카운트:** `quartz/plugins/emitters/folderPage.tsx` line 107 `FolderContent({ sort: userOpts?.sort, showFolderCount: false })`로 옵션 박음. quartz core 수정이지만 우리 자체 clone이라 fork 부담 X.
4. **로컬 검증** — `rm -rf public && npx quartz build` → 5s, 204 files emit OK. `grep` 결과: `/diary/index.html`에 `2026.05.15` 다수, 영문 `May 15` 0건. `/diary/a/index.html`에 "under this folder" 0건. `/index.html`도 `2026.05.15` 정상.
5. **commit + push** — `8cf9f0a feat: 날짜 YYYY.MM.DD + 폴더 카운트 숨김 (#T-C-116)`. 2 files / +7 / -6. push OK.

### 배운 점 (← dream 입력)
- **패턴/원칙:** Quartz emitter가 컴포넌트 옵션을 일부만 forward할 때 외부에서 옵션 못 박음 — emitter 한 줄 수정으로 길 뚫는 게 i18n 키 비우기·monkey-patch보다 훨씬 깔끔. 같은 결: "옵션 인터페이스에 정의돼 있는데 forward 안 되면 emitter 패치가 정답."
- **새로 통한 것:** `toLocaleDateString` 한 줄로 박힌 format은 옵션 변경 없는 우리 케이스에서 통째 교체 더 간단. 한국식 점 구분 포맷은 ICU에 옵션 없어서 수동 padStart가 외려 깔끔.
- **막힘 회복:** 백그라운드 `until curl | grep` 잡이 마지막 `grep -c "under this folder"` exit 1(0건 매치)로 전체 exit 1 떨어졌는데 — 출력은 정상이라 결과 OK. 백그라운드 잡 exit code != 검증 결과, 출력 직접 읽기.
