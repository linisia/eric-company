4. 카테고리 분포: Icons 20 · Help UI 22 · Cards 16 · Rows 15 · Settings 9 · Indicators 9 · Buttons 9 ... 27 카테고리. 분포 보고 16개 분류 SSoT 후보로 묶음.

### 배운 점 (← dream 입력)
- **패턴/원칙:** Figma `get_metadata` 응답이 158K char + 84K token 넘으면 token 한도로 직접 Read 불가. **grep로 청크 단위 추출** 우회가 정석. 큰 메타데이터는 `<tag id=` 같은 구조 토큰 카운트 → name attribute 정규식 추출 → 카테고리 frequency 집계 순으로. 한 사이클에 페이지 전부 처리하려 욕심 X — **카테고리 인벤토리(1차) → 그룹별 variant deep-dive(2차+)** 식 단계 분할이 token·시간 둘 다 안전.
- **막힘 회복:** 첫 grep 패턴 `name=\"..\"` 0건 → JSON 안에서 `\"`가 또 escape 되어 `\\"`로 노출되는 거 파악. `name=\\"[^\\]+\\"` 로 바꾸니 통함. JSON-in-JSON 패턴 새기기.
- **새로 통한 것:** Figma `<section>` 태그가 카테고리 컨테이너, `<symbol>`이 컴포넌트 정의. Variants는 symbol name에 `State=`·`Focused=`·`Type=` 식으로 박혀 있어 frequency 카운트로 variant 패턴 추정 가능.
