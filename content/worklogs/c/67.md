## #67 🌱 film-writing-style 스킬 업그레이드 (탑 세션 피드백 → analyze·author·verify 2-워크플로 사이클)

- 일자: 2026-06-05
- 작업자: 최대리
- 지시: Eric (ultracode)

> "이번 세션에 귀담아 들은 것들 분석하고 글로벌 스킬 업그레이드 검토·반영. 다시 처음부터 끝까지 검토해서 가장 최신으로."

### 시작
《탑》 평론 완결 직후, 그 세션에서 Eric이 준 피드백 20개를 글로벌 스킬에 누적·정련하고 '바로 쓸 수 있는 최신' 상태로 만드는 메타 작업.

### 실행
1. **분석 워크플로**(4렌즈: 신규규칙/기존강화/모순·중복/구조·최신성) — 피드백 20개 분류, 충돌 3~4개에 경계 절 도출.
2. **발견**: 다른 계정(d)이 그새 SSoT에 4라운드〈어쩔수가 없다〉(항목19~24)+재독 절차를 추가해 둠 → 내 탑은 5라운드. 중복 회피하며 통합.
3. **반영(13편집)**: 5라운드 신규 6항목(25~30 평결=메뉴·도입메타·형식/실물검증·강조점결론↔열어둔것·straw-man·검수재대조) + 기존 보강(7·14·15·여백·18·문체1·2) + **'🚨 시작 전 30초 절대 철칙' 진입화면 신설** + 체크리스트·생성프롬프트·메타데이터 동기화.
4. **검수 워크플로**(3렌즈: 완결성·일관성/잡힘테스트/항해성) — major 2(③통째 일반화 누락, 체크리스트 '4번째 사본' 비대) + minor·nit. **7편집 보강**(일반화 함정 항목27·체크리스트 6→3 압축·항목6 forward-ref·AI점검에 grep 게이트·항목25/21 경계·침대 백미 예시·30초 명명 가시성).
5. **구조 무결 검증**: 항목 1~30 연속(빠짐·중복 0), 깨진 참조 0, 생성프롬프트 16~19 추가. (550→607줄, 4계정 전파.)

### 결과
- `film-writing-style/SKILL.md` — 탑 세션 피드백 20개 전부 반영(누락 0), 충돌 4개 경계 절로 해소, 30초 진입점 신설 ✅
- 검수 2개 major + 다수 nit 다 처리, 구조 무결 ✅

### 배운 점 (← dream 입력)
- **패턴/원칙:** 누적 규칙 스킬은 'round 추가'만으로 금세 비대해진다 → (a) refine로 흡수 (b) 진짜 신규만 라운드 (c) 30초 진입점+grep 게이트로 항해성 확보. 다음 세션 피드백 통합도 이 3원칙.
- **막힘 회복:** 공유 SSoT는 병렬 갱신된다(d가 4라운드 추가) → 편집 전 반드시 최신 Read로 중복·번호 충돌 확인. 그리고 **Skill 로드는 Edit 추적에 안 잡혀** 별도 Read가 필요(이번에 "File has not been read yet" 에러로 학습).
- **새로 통한 것:** analyze→(내가 author)→verify **2-워크플로 사이클**이 스킬 진화에 효과적. 검수가 '통째 일반화' 같은 *내가 놓친 함정*을 실제로 잡아냄 — author/verify 분리의 값.
