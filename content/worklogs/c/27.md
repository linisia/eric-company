### 시작
큐 첫 미처리 = #T-C-115. 본 발주(그래프·검색 누출) + 추가 항목(Explorer fixtures·meta 숨김 + callout 다크 컬러) 한 묶음. 큼직 — Step 1 진단만 이번 사이클, Step 2 픽스/Step 3 배포는 다음 사이클로 분할.

### 실행
1. `quartz.layout.ts` 확인 — content layout `right: [Component.Graph(), ...]`, list layout `right: []`. 메인은 list라 그래프 X 같지만 Eric 보고는 메인 우측에 그래프 노출. → list/content 둘 다 점검 필요. (실제 그래프 컴포넌트가 어디서 노출되는지 빌드 단에 확인 다음 사이클.)
2. `quartz/components/Graph.tsx` 옵션 — `D3Config`에 `removeTags`/`showTags`만 있음. **path 기반 제외 옵션 X.** 데이터 소스는 `graph.inline` 스크립트가 `contentIndex.json` JSON fetch.
3. `quartz/components/Explorer.tsx` 옵션 — `filterFn: (node: FileTrieNode) => boolean` 있음. 기본 `node.slugSegment !== "tags"` 식. → **`/worklogs/`, `/fixtures/`, `/meta/` 제외 가능, 깔끔.**
4. `quartz/plugins/emitters/contentIndex.tsx` — sitemap.xml / RSS xml / contentIndex.json 세 산출물 모두 emit. **path-exclude 옵션 X.** 모든 content를 다 인덱싱. 옵션 추가하면 그래프(JSON 소비)·검색(JSON 소비)·sitemap·RSS 동시 제외 — 일거사득.
5. 결론 정리 — Step 2 픽스 방향 확정.

**Step 2 픽스 계획 (다음 사이클):**
1. `quartz/plugins/emitters/contentIndex.tsx`에 `excludePatterns?: string[]` 옵션 추가 — slug가 `worklogs/`로 시작하는 항목 인덱스 제외. (자체 패치 — monkey-patch 최소화.)
2. `quartz.config.ts`에서 `Plugin.ContentIndex({ excludePatterns: ["worklogs/"] })` 적용.
3. `quartz.layout.ts`의 `Component.Explorer({ useResolvedTitle: true })`에 `filterFn` 옵션 추가 — `node.slugSegment !== "tags" && !["worklogs", "fixtures", "meta"].includes(node.slugSegment)` (또는 fullPath 기반).
4. callout 다크 토큰은 `quartz/styles/custom.scss` 또는 callout SCSS — Step 2에서 ec-dark-text 변수 매핑.
5. 로컬 빌드 → `grep -ic "worklogs" public/index.html` = 0 검증.

### 배운 점 (← dream 입력)
- **패턴/원칙:** SSG에서 메타데이터 누출(그래프·검색·sitemap·RSS·oG image) 차단은 *콘텐츠 소비 컴포넌트마다* 옵션 박는 게 아니라 *공통 인덱스 emitter*에서 차단하는 게 가장 깔끔. 옵션 한 곳 → 모든 소비 컴포넌트 자동 정리. 다음에 같은 패턴 만나면 "데이터 소스 emitter가 뭔지" 먼저 좁힌다.
- **새로 통한 것:** Quartz Plugin vs Component 분리 — emitter는 데이터를 만들고 component는 그 데이터를 소비. 데이터 게이트는 emitter 측이 1순위. Component 측 필터는 보조 (Explorer처럼 emitter 거치지 않는 컴포넌트에만).
- **막힘→통함:** Graph·Search 각각에 옵션 추가하려다 `D3Config`·search.inline.ts 봤더니 없음 → ContentIndex emitter 한 곳 패치로 동시 해결. "옵션 없네 → 패치" 결심 빠르게 한 게 좋았음.
