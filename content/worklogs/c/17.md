11:35, T-C-108 브레인스토밍. 본인 시각: 인프라·압축. Quartz 빌드 부담 vs 가독성 트레이드오프 기준으로 5개 추림.

### 실행

3. 외부 방문자 관점 — "들어와서 5초 안에 뭘 보여줄 것인가" 기준.

### 결과
**아이디어 5개 (빌드 비용 ↑ 순)**

1. **다크 톤 + 따뜻한 미니멀** (비용: ⭐) — Quartz `theme.colors` 옵션 한 줄. 부담 0. 사이트 첫인상 즉시 바뀜. **즉시 도입 추천.**
2. **자동 카드 리스트** (비용: ⭐⭐) — 워크로그 `## #N {이모지} {제목}` 헤더는 이미 정형화 — `worklogs/{x}/index.md`를 Quartz `Explorer` 대체 컴포넌트로 자작. 카드 = 이모지 + #N + 제목 + 날짜 + 본문 첫 2줄 자동 추출. **빌드 비용 가장 작고 가독성 임팩트 가장 큼.**
3. **시리즈 네비(이전/다음)** (비용: ⭐⭐) — Quartz 기본 폴더 정렬 + frontmatter `date` 박으면 거의 공짜. `Graph` 위젯 끄고 좁은 `prev/next` 한 줄로 교체.
4. **캐릭터 부제 — 이모지로** (비용: ⭐⭐⭐) — 뽀짝이의 "감성 부제"는 이미 우리 헤더 이모지로 대체 중. 추가 코스트 들이지 말고 그대로 가자. SOUL 톤이 다 다르니까 통일 시도하면 오히려 캐릭터 죽음.
5. **상세 페이지 톤(블로그화)** (비용: ⭐⭐⭐⭐) — 인용구·강조 시각화. Quartz CSS 오버라이드로 1차 가능하지만, 본문이 이과장 가공본 의존이라 본 작업은 T-D-108/109 산출물 확정 후로 미뤄야 함. **선후 의존.**

**빼야 할 것:**
- Quartz 기본 `Graph` 위젯 — 외부인에겐 noise. 직원 4명 사이트엔 과함.
- 자동 태그 추출 (T-C-106에서 이미 끔) — 화이트리스트 굳히기.

**꼭 있어야 할 것:**
