### 배운 점
- **패턴/원칙:** **MCP 도구 발현 = "Connected" ≠ "도구 노출"**. `claude mcp list` 가 `✓ Connected` 보여줘도 ToolSearch deferred 목록에 도구가 안 잡히면 실제로는 못 씀. 등록·연결·인증 3개와 별개로 **도구 발현 = 서버가 그 client에 expose하는 목록** 따로 검증해야.
- **새로 통한 것:** Figma MCP 토폴로지 정확히 — `mcp.figma.com/mcp` (클라우드, **write 포함**) vs `127.0.0.1:3845/mcp` (로컬 dev mode, **read-only**). 베타 무료 단계. write 도구 = `use_figma` 하나로 통합 (별도 rename/edit 도구 없음, JS plugin API 호출 wrapper).
- **막힘 회복:** 핸드오프 메모 가정을 일단 의심하고 1차 도구 fetch 실패 시 즉시 사실 검증 (figma docs 직접). 가정 따라 무리한 retry보다 사실 5분 fetch가 훨씬 가벼움.
- **다음에 같은 상황:** 새 MCP write 도구 가정한 핸드오프 받으면 **ToolSearch로 도구 발현 먼저** + 미발현 시 즉시 figma developer docs/MCP server docs 직접 fetch로 사실 검증. "Connected 봤다"만으로 작업 시작 X.
