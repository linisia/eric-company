### 시작
14:05경, `localhost:8765` 진단부터. v1 코드 박힘(#37)인데 떠있는 process가 v0 (PID 89204, 52분째). `/api/tasks` 404로 v0 확정 → v0 kill → v1 재기동(PID 10733). 그래도 4명 다 idle 표시. 원인 분석 들어감.

### 실행
1. **원인 추적** — `status/c/current.json` 직접 봤더니 `state="idle"`. `scripts/` 3개 검토. `session-start.sh`는 active 박지만 매 응답 끝마다 `stop.sh`가 idle로 덮어씌움. `tool-marker.sh`는 marker 파일만 touch, state 안 건드림. PreToolUse hook은 eric_company 무관. → 거의 항상 idle 모델 문제.
2. **SessionEnd hook 없음 확인** — `~/.claude/hooks` / `settings.json` 둘 다 SessionEnd 없음. 진짜 세션 죽음 신호 못 받음 → `last_updated` stale 감지로 가는 게 맞음.
3. **3결 박음 (직접 fix, 결재요청 X — Eric 지시)**
   - `scripts/tool-marker.sh`: PostToolUse마다 `.state="active" | .last_updated=$NOW` 갱신 추가
   - `scripts/stop.sh`: `.state="idle"` 박는 라인 제거. last_task/current_task 정리는 유지
   - `tools/dashboard/index.html` `deriveState`: `last_updated`가 5분+ stale이면 active 무시하고 idle 반환
4. **검증** — Bash 1회 호출 후 c status 즉시 `{"state":"active","last_updated":"2026-05-18T06:07:36Z"}` 박힘. a/b/d는 last_updated 옛날 → stale=idle 정상.
5. **OMC 업그레이드** — `omc` CLI PATH 미설치. plugin 캐시 `~/.claude/plugins/cache/omc/oh-my-claudecode/4.13.1/bridge/cli.cjs update` 직호출. 결: **4.13.1 → 4.14.0**, plugin/npm/CLAUDE.md 셋 다 sync (CLAUDE.md `<!-- OMC:VERSION:4.14.0 -->` 자동 박힘). 세션 재시작 필요.

### 배운 점 (← dream 입력)
- **패턴/원칙:** "응답 종료 = 세션 종료"가 아님. Claude Code Stop hook은 매 응답마다 도는 거지 세션 죽음 신호 아님. 세션 라이프사이클 표시는 `last_updated` stale 감지로 해야 정확. 같은 모델: 워치독식 표시 = "신호 박는 곳" + "신호 stale 감지하는 곳" 두 결로 쪼개야 깔끔.
- **막힘 회복:** plugin CLI가 PATH에 없어서 `omc` 못 찾았을 때, `~/.claude/plugins/cache/omc/oh-my-claudecode/{ver}/bridge/cli.cjs`를 node로 직접 호출. plugin이 npm 글로벌 설치 없어도 자기 bridge CLI를 박아둠. 같은 결 또 만나면 `find ~/.claude/plugins -name "cli.*"`로 빠르게 잡기.
- **새로 통한 것:** OMC plugin 진짜 npm 패키지명은 `oh-my-claude-sisyphus`. registry에서 `oh-my-claudecode`는 0.2.8(별 트랙), 진짜 최신은 sisyphus 4.14.0. plugin 통합 버저닝이 따로 있음.
