## #4 🛠️ #T-C-101-step2 content 매핑 + 공개 게이트

- 일자: 2026-05-14
- 작업자: 최대리
- 지시: 김부장

> "워크로그 v2를 Quartz가 빌드 가능하게 + 메타.공개: public 만 노출."

### 시작
큐 첫 미처리 H3 = `#T-C-101-step2`. step1 완료 확인됨 (#3 워크로그). 즉시 착수.

### 실행
1. Drive Vault 구조 확인 — `log/{a,b,c,d}.md`, `soul/{a,b,c,d}.md`, `templates/worklog.md` 목록·메타.공개 라인 위치 grep.
2. 빌드 전처리 스크립트 `scripts/sync-content.mjs` (Node ESM) 작성. 정책:
   - `## #N {이모지} {제목}` 헤더 단위 split → 섹션 내 `- 공개: …` 정규식 감지.
   - public/없음 → 그대로 / password → 본문 제거하고 헤더+메타만 + 🔒 placeholder / private → 섹션 자체 제외.
   - soul·templates 는 단순 복사 (운영 문서, 공개 게이트 미적용).
3. dummy 픽스처(public/password/private 1개씩)로 정규식 회로 검증 — 3건 모두 정확히 분기 ✅.
4. `npx quartz build` — 첫 시도 9 input. `templates/` 가 Quartz 4 예약 디렉토리라 무시됨 발견 → 출력 경로 `meta/worklog-template.md`로 변경.
5. 재빌드 → 10 input parse, **75 emit in 622ms** ✅. public/{index, worklogs/{a,b,c,d}.html, souls/{a,b,c,d}.html, meta/worklog-template.html, tags/*} 전부 생성.
6. 큐 헤더 ✅ 마킹.

### 결과
- 스크립트: `~/eric-company-site/quartz/scripts/sync-content.mjs`
- 파서: 같은 파일 내 `processWorklog()` / `detectVisibility()` / `renderPasswordPlaceholder()`
- index 자동 생성 + worklogs/{a~d} + souls/{a~d} + meta/worklog-template
- 실 데이터 분포: 워크로그 16편 전부 public (v1 양식은 메타 누락 → public 기본값) ✅
- 분기 회로 검증: dummy fixture로 public/password/private 정확히 라벨링 ✅

### 배운 점 (← dream 입력)
- **패턴/원칙:** Quartz 4는 content 하위 `templates/` 디렉토리를 예약(layout)으로 취급해 input에서 제외. 사용자 콘텐츠로 같은 이름 쓰면 사일런트 누락 — input 카운트와 emit 카운트 차이로 감지. **공개·드라이브 동기화 시 reserved name 충돌부터 점검할 것.**
- **막힘 회복:** "Found 9 input files"인데 우리 입력은 10이어야 함 → 디렉토리명만 `meta/` 로 바꿔 즉시 통과. 원본 이름 보존보다 빌드 통과가 우선.
- **새로 통한 것:** 섹션 split 후 last-match `- 공개:` 정규식 — 메타 블록이 맨 끝에 있다는 v2 양식 특성을 활용. 첫-match보다 last-match가 본문 인용 오탐 회피.
